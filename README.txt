1029 EMAIL 寄送表單作業
======================

檔案：
- index.html：首頁
- about.html：公司介紹
- contact.html：聯絡我們（表單收件信箱已設定為 sslin0315@gmail.com）

部署與測試：
1. 將三個 HTML 檔案上傳到同一個 GitHub repository。
2. 在 GitHub repository 的 Settings > Pages 啟用 GitHub Pages。
3. 開啟線上 contact.html，填寫測試資料並按「送出表單」。
4. 第一次使用 FormSubmit，請到 sslin0315@gmail.com 收件匣（也檢查垃圾郵件）查看驗證信並按確認連結。
5. 驗證完成後，再從線上網站送出一次測試表單，確認收到包含表單內容的郵件。
6. 將送出畫面與 Gmail 收件畫面展示給老師。

注意：
- 只有在收件信箱完成 FormSubmit 首次驗證後，寄送才會正常進行。
- 本範本使用第三方 FormSubmit 服務；實際收信狀態需由你在線上送出後確認。
- 若老師要求看到成功證據，請務必使用部署後的網站測試，不要只在本機直接開啟 HTML。
